03

快速开始

Node ≥ 22，免构建，原生跑 .ts
# 拉取 & 安装
git clone https://github.com/1281227309-art/shangjiu
cd shangjiu
npm install          # 或 pnpm install

# 启动 MCP 服务器（stdio，等宿主调用）
npm start

# 免 npm 快速验证工具层
node scripts/demo.mjs
  • 薄插件：标准 MCP 协议，不做独立 App
  • 知识独立于协议：数据/业务层为纯模块，可脱离 MCP 复用
  • 无依赖演示：demo / review 脚本免 SDK 直接跑
  • 诚实数据：✅已核实 / 🟡待厂方确认 / ⬜待采集
04

接入你的 AI 宿主

Trae（推荐 · 国内可用）

Trae → 设置 → MCP → 添加，类型 stdio，命令填项目绝对路径。

// 命令
node /path/to/shangjiu/src/index.ts

Claude Desktop（一键）

运行脚本即合并进 Claude 配置，完全退出重启即可。

bash scripts/install-claude-config.sh

通用 stdio 配置

{ "mcpServers": {
    "shangjiu-guowei": {
      "command": "node",
      "args": ["/path/to/shangjiu/src/index.ts"]
    } } }

Cursor

// ~/.cursor/mcp.json
{ "mcpServers": { "shangjiu-guowei":
  { "command": "node",
    "args": ["/path/to/shangjiu/src/index.ts"] } } }

数据层 · 社区共建

真实数据，才进知识库
  • 来源可查：每字段带 source 与 confidence
  • 可信度三档：✅ 已核实 / 🟡 待厂方确认 / ⬜ 待采集
  • 品鉴只收真人：submit_tasting_note → 复核 → curated → 进库
  • 小厂共建：帮它们"定义你是谁 + 给声量"，换一手数据与授权
真人品鉴 / 厂方一手信息
     │  submit_tasting_note（只收集，不判断）
     ▼
  品鉴数据池 (pending_review)
     │  scripts/review.mjs  复核
     ▼
  curated (approved) → 人工判断 → src/data.ts
06

诚实，是这套东西的资产

01
不编造品鉴笔记、价格、工艺，凡无一手来源一律留空标注。
02
AI 只整理，不判断AI 做归并、可视化、追踪；不做主观品鉴结论。
03
出处可查每个字段带 source，任何引用都经得起核查。
04
待采即待采标 ⬜ 的不作结论，不等厂方确认不硬讲。
