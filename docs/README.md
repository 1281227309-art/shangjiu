## ⚠️ 两份厂家表单的关系（重要）

`厂家表单.html` 与 `厂家内容表单.md` **内容等价、渠道不同**——不是重复，是两种交付方式：

```
                    ┌─────────────────────────────┐
                    │  同一份厂家内容采集表单      │
                    │  字段一律以 src/data.ts 为准 │
                    └──────────────┬──────────────┘
                                   │
              ┌────────────────────┴────────────────────┐
              ▼                                          ▼
   ┌────────────────────┐                    ┌────────────────────┐
   │ 厂家表单.html       │                    │ 厂家内容表单.md     │
   │ 【在线 / 链接】     │                    │ 【离线 / 文件】     │
   ├────────────────────┤                    ├────────────────────┤
   │ · 实时生成 JSON     │                    │ · G 区手填 JSON     │
   │ · 草稿自动保存      │                    │ · I 区附件清单      │
   │ · 一键提交 Issue    │                    │ · 可打印 / 转 Word  │
   │ · 即时必填校验      │                    │ · 随文件一起回传    │
   └────────────────────┘                    └────────────────────┘
              │                                          │
              └────────────────────┬─────────────────────┘
                                   ▼
                     人工核对 source + confidence
                                   ▼
                        进入 src/data.ts
```

### 维护规则（必须遵守）

1. **字段以代码为准**：唯一权威是 `src/data.ts` 的
   `Distillery` / `ProcessInfo` / `TerroirInfo` / `FlavorInfo` / `Product` 接口。
2. **先改代码，再同步两份表单**——两份表单的字段必须始终一致。
3. **按渠道选用其一**，不要让厂方两份都填。
4. HTML 版中的字段→代码映射注释（`<code>name</code>` 等）需与 MD 版保持一致。

### 各版本独有内容

| | HTML 版独有 | MD 版独有 |
|---|---|---|
| 功能 | 实时 JSON、草稿保存、一键提交 Issue、即时校验 | — |
| 内容 | — | G 区结构化 JSON 区、I 区附件清单 |

> 若将来只保留一份：**保留 HTML 版**（体验更好），把 MD 版降级为纯「字段说明书」（只留字段→代码映射 + JSON schema）。
