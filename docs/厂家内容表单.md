# 上九 · 国威知识库 —— 厂家内容采集表单（离线 / 存档版）

> **📌 本文件定位（重要，勿与 HTML 版混淆）**
>
> | 版本 | 渠道 | 什么时候用 |
> |---|---|---|
> | **本文件（Markdown · 离线版）** | 离线 / 文件传递 | 需要**发文件给厂方**（微信、邮件）、需要**打印**、需要**转 Word/PDF** 走正式流程时 |
> | `厂家表单.html`（网页版） | 在线 / 链接传递 | 对外**只发一个链接**，厂方在网页上填写：自动校验、实时生成 JSON、可一键提交 GitHub Issue |
>
> - **字段一律以 `src/data.ts` 为准**。两份表单字段必须保持一致；将来新增字段时，**先改代码，再同步两份表单**。
> - 本版**独有**：G 区手填 JSON、I 区附件清单（适合随文件一起回传）。
> - 网页版**独有**：实时 JSON 生成、草稿自动保存、一键提交。
> - 两者**内容等价**，按渠道选用其一即可，不必让厂方两份都填。

---

> **用途**：本表单用于**厂方一手资料的采集与共建**。你填写的每一条，都会带 `source`（来源）与 `confidence`（可信度）进入「上九 · 国威知识库」，供 AI 在讲中国威士忌时准确引用。
>
> **我们认为**：国产威士忌缺的不是酒，是一套「人人能读、人人能引用、经得起核查」的讲法。这个表单就是让厂方**把「你是谁」定义成标准**的入口。

## 填写须知（请先读）

**① 诚实守则（很重要）**

- **不编造**：凡无一手来源的品鉴笔记、价格、工艺细节，**一律留空**并在备注里写「待采集」。留空不丢分，编造才会。
- **有据可查**：每个字段请尽量给出**来源**（官网链接 / 产品手册 / 官方公众号推文 / 厂方书面确认）。
- **待采即待采**：不确定的项，宁可不填，也不要用估算数。
- **AI 只整理不判断**：主导风味词由**真人盲品聚合**得出，我们会把厂方描述与社区反馈分开标注，AI 不做主观背书。

**② 可信度自评（每项请标）**

| 标注 | 含义 | 使用场景 |
|---|---|---|
| ✅ `verified` | 已有可查来源，可用 | 厂方官网/手册明确写明的 |
| 🟡 `pending` | 待厂方确认 | 你凭印象填写、需内部再确认的 |
| ⬜ `unverified` | 待采集 | 暂缺，留空即可 |

## B. 工艺

> 对应数据结构：`ProcessInfo`

| 字段 | 请填写 | 对应代码字段 |
|---|---|---|
| **麦芽 / 原料**（大麦品种、是否国产麦、是否用青稞/谷物等） | | `malt` |
| **酵母**（菌种 / 是否自培 / 是否有特殊酵母） | | `yeast` |

| **桶型体系**（波本桶 / 雪莉桶 / 中国橡木 / 蒙古栎 / 麻栎 / 茶桶 / 黄酒桶 / 风味桶…请具体） | | `cask` |
| **陈酿时间**（最低年份 / 主力年份 / 是否有原桶强度） | | `maturation` |

> **重点提示**：**中国本土桶型**（蒙古栎、麻栎、中国橡木、茶桶、黄酒桶等）是你的差异化资产，请务必写清楚——这是「东方风味」讲法的核心。

## H. 你希望我们怎么讲你？（开放题）

1. 你最希望被记住的**一个点**是什么？（一句话）
2. 有没有被媒体/营销号**讲错过**的地方？想纠正什么？
3. 你最不想被拿来比较的对象是谁？为什么？
4. 有没有**独家故事**（创始契机、技术攻坚、某次失败的实验）愿意讲？
5. 未来 1–2 年，你最想做出来的**那一款酒**是什么样？

> 这五个问题不填也无妨，但它们往往决定「你的声量」——我们帮小厂做的是**把「你是谁」定义成标准 + 给声量**。

## 附：这份表单填完之后会发生什么？

```
你填写的表单（一手信息）
        │  人工核对 source + confidence
        ▼
   进入知识库  src/data.ts（带 ✅/🟡/⬜ 标注）
        │
        ▼
   AI 在回答「国产威士忌有哪些东方风味的厂」时，
   会引用你的真实数据，并诚实标注未核实项
        │
        ▼
   你的厂被「正确地讲清楚」——这就是声量
```

**同时**，你还可以用知识库的 `submit_tasting_note` 工具提交**真人品鉴**：

```
真人品鉴 → submit_tasting_note（AI 只收集，不判断）
        → data/tasting-input.jsonl（状态 pending_review）
        → scripts/review.mjs 复核 → 通过才进知识库
```
