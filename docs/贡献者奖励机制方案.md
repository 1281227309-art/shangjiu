# 贡献者奖励机制 · 方案（v1）

> 上九 · 国威知识库 —— 让「把中国威士忌讲对」这件事，从一个人的执念，变成一群人的事业。

---

## 1. 背景：为什么需要奖励机制

「上九 · 国威知识库」的定位很清楚：

- **知识中枢**：数据才是护城河，不是产品；
- **诚实数据**：每条带 `source` + `confidence`，不编造、不背书；
- **品鉴漏斗**：真人品鉴 → 复核 → 才进库。

但这里有一个结构性矛盾：

> 知识库的价值**取决于持续的真实数据流入**，而「贡献数据」是一件**费时、无即时回报、且容易被搭便车**的事。

如果没有奖励机制，会出现：
1. **贡献者流失**：少数人默默付出，没有认可，热情耗尽；
2. **数据停滞**：护城河变护城沟，知识库失去更新；
3. **被搭便车**：AI 宿主、内容创作者白嫖数据，无回流。

所以奖励机制的目的不是「发钱」，而是：**让贡献可持续、让价值可回流、让诚实可被激励。**

---

## 2. 核心原则（三条，不可妥协）

**① 只奖励「进库」的贡献，不奖励「提交动作」。**
按提交量发奖 = 鼓励刷假数据 = 毁掉诚实这个护城河。

**② 奖励「可验证」与「可追溯」。**
每条贡献带 `source`、`contributedBy`，进库即留痕，榜单可查。

**③ 非货币优先，货币化延后。**
现阶段无收入，先靠声誉、特权、体验；变现是「有收入之后」的事，绝不提前透支。

---

## 3. 五类贡献者画像

| 画像 | 动机 | 他们要什么 |
|---|---|---|
| 🥃 **威士忌爱好者** | 热爱、想被认可 | 署名、荣誉、盲品会名额 |
| 📇 **数据极客** | 较真、喜欢把事弄对 | 署名、可信度权威感 |
| 🛡️ **专业复核者**（侍酒师/从业者） | 专业声望 | 「可信复核者」头衔、行业内影响力 |
| 📣 **内容创作者** | 涨粉、变现 | 流量、分成（未来） |
| 💻 **开发者** | 技术乐趣、开源声誉 | PR 合入、项目背书 |

> 关键洞察：**不同人要的东西不同**。奖励机制必须分层，不能用「一样东西」激励所有人。

---

## 4. 奖励设计：四级递进

### L1 声誉（零成本，立即上线）
- 荣誉榜 `CONTRIBUTORS.md` 署名；
- `data.ts` 的 `contributedBy` 字段署名（已实现）；
- 等级徽章（起步 → 熟客 → 老饕 → 元老）。

### L2 特权（少量开发）
- 快速复核通道；
- 数据审核权（元老级）；
- 内测、提前获取新数据。

### L3 体验（靠厂方合作，差异化核心）⭐
这是本项目**最能打**的一级，因为它激活了「厂方共建」飞轮：

```
贡献者提供真实品鉴/数据
   → 知识库更可信、更值钱
   → 厂方更愿意合作（为了「被正确讲清楚」）
   → 厂方拿出：样品、盲品会名额、酒厂参观、限量酒
   → 反哺优质贡献者
   → 继续贡献
```

### L4 变现（有收入后）
- 内容导购佣金分成；
- 数据授权费按贡献比例分成；
- 厂方悬赏（bounty）：出钱请人「把某家资料补全 / 核实」。

---

## 5. 与「诚实数据」原则的关系（最关键）

奖励机制最大的风险是**激励造假**。对策有三：

1. **结算点后移**：奖励挂在「进库」，不挂在「提交」。假数据到不了进库那一步，拿不到分。
2. **复核把关**：品鉴走 `review.mjs` 真人复核；数据靠 `source` + `confidence` 人工核对。
3. **连带责任**：复核者放行假数据要担责（徽章降级）。让「把关的人」和「造数据的人」利益分离。

> 一句话：**奖励「求真」，不奖励「求多」。**

## 6. 落地路线图

| 阶段 | 交付 | 依赖 |
|---|---|---|
| **P0 现在** | `contributedBy` 字段（✅已做）、`CONTRIBUTORS.md`、奖励规则、榜单页 | 无 |
| **P1 短期** | 榜单页 + 自动统计（GitHub Action）、等级徽章 | 少量开发 |
| **P2 中期** | 复核权限分层、快速通道、厂方体验奖励试点 | 厂方合作 |
| **P3 长期** | 变现分成、bounty、赞助（GitHub Sponsors） | 有收入 |

---

## 7. 度量指标（怎么算成功）

| 指标 | 含义 | 目标（季度） |
|---|---|---|
| 进库贡献数 | 被复核通过的数据/品鉴条数 | 持续增长 |
| 活跃贡献者数 | 每季度至少 1 次进库贡献的人 | ≥ 5 人 |
| 数据覆盖率 | 14 家酒厂中「已核实」比例 | 从 5/14 提升 |
| 复核通过率 | 品鉴漏斗 approve 占比 | 稳定、无假数据漏网 |

---

## 8. 风险与对策

| 风险 | 对策 |
|---|---|
| 刷假品鉴/数据 | 结算点后移 + 复核把关 + 连带责任 |
| 复核者被公关 | 复核者署名公开、可追责、多复核者交叉 |
| 厂方不配合 | L3 体验奖励是「增量」，厂方不配合不影响 L1/L2 运转 |
| 变现遥遥无期 | 先用声誉/特权/体验维持，不强推货币化 |

---

## 附：一页纸总结

> **上九国威知识库的贡献者奖励机制 = 让「讲对中国威士忌」变成一份可持续、可追溯、值得做的公共事业。**
>
> 铁律：只奖励进库的贡献。
> 四层：声誉 → 特权 → 体验 → 变现。
> 飞轮：贡献者 ⇄ 知识库 ⇄ 厂方。
> 底线：宁可慢，不可假。
