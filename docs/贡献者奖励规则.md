# 贡献者奖励规则（v1）

> 上九 · 国威知识库 —— 让贡献被看见、被回报、可追溯。
> 本文是**可执行规则**；战略层面的设计见 [`贡献者奖励机制方案.md`](贡献者奖励机制方案.md)。

---

## 0. 总则：一条铁律

> **只奖励「被复核进入知识库」的贡献，不奖励「提交动作」本身。**

原因：知识库的护城河是「诚实数据」。若按提交数量发奖，就会有人刷假品鉴、编数据，反而毁掉最值钱的东西。所以奖励一律挂在**「进库」**这一环。

---

## 1. 贡献者类型与积分

| 类型 | 行为 | 积分 |
|---|---|---|
| 🥃 品鉴者 | 1 条品鉴笔记被复核进库 | **+1** |
| | 该品鉴带来源（`source`） | 额外 **+1** |
| 📇 数据贡献者 | 新增 / 更正 1 家酒厂（带 source） | **+5** |
| | 新增 / 更正 1 个产区 | **+5** |
| | 补核 / 更正 1 条价格 | **+2** |
| | 补核 1 条风味 / 工艺 / 风土 | **+2** |
| 🛡️ 复核者 | 复核通过（approve/reject）累计 10 条 | **「可信复核者」徽章** |
| 📣 内容传播者 | 产出 1 篇带出处的内容并回传 | **+2** |
| 💻 开发者 | 合入 1 个 PR | 按贡献量评估（1–10） |

---

## 2. 等级与徽章

| 等级 | 累计积分 | 徽章 | 权益 |
|---|---|---|---|
| 起步 | 1–9 | 🥃 | 登上荣誉榜 `CONTRIBUTORS.md` |
| 熟客 | 10–49 | 🥃🥃 | 荣誉榜置顶 + 「可信贡献者」标识 |
| 老饕 | 50–199 | 🥃🥃🥃 | 提交**优先复核**（快速通道） |
| 元老 | ≥200 | 🏆 | 数据审核权 + 厂方体验奖励优先 |

**「可信复核者」徽章**（独立维度，非积分）：
- 复核通过 ≥ 10 条 → 获得；
- 获得后其提交**优先审、初始可信度更高**；
- 若被证伪的复核 > 3 条，徽章收回。

---

## 3. 奖励形式（从零成本到未来变现）

| 级别 | 形式 | 现状 |
|---|---|---|
| L1 声誉 | 荣誉榜署名、徽章、`contributedBy` 署名 | ✅ 现已可用 |
| L2 特权 | 快速复核通道、复核权、内测 | 🔜 需少量开发 |
| L3 体验 | 样品、盲品会名额、酒厂参观（由厂方提供） | 🔜 需厂方合作 |
| L4 变现 | 未来内容导购 / 数据授权 / 品牌服务分成 | 📅 有收入后 |

---

## 4. 结算与追溯

1. **署名**：数据贡献在 `src/data.ts` 对应条目的 `contributedBy` 字段留名；品鉴在 `review.mjs` 复核记录留 reviewer。
2. **榜单**：`.github/workflows/contributors.yml` 自动从 git 历史 + `contributedBy` 字段统计积分，生成 `contributors.json`，驱动 `contributors.html` 榜单页。
3. **公开**：榜单页在 GitHub Pages 上线，任何人可查。

---

## 5. 惩罚与撤销

- **编造数据 / 假品鉴**：撤销积分、移出荣誉榜、`contributedBy` 署名清除。
- **复核失职**（放行明显假数据）：徽章降级或收回。
- 诚实守则高于一切：**宁可慢，不可假**。

---

## 6. 与厂方共建的衔接

厂方提供的**样品 / 盲品会名额 / 参观**，作为 L3 体验奖励，**优先发放给榜单前列**——这形成闭环：

```
贡献者提供真实品鉴/数据 → 知识库更可信 → 厂方更愿合作
   → 厂方提供体验资源 → 反哺优质贡献者 → 继续贡献
```
