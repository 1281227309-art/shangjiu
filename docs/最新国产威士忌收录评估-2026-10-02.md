## 二、准入门槛（本次判定所用标准，源自 `CONTRIBUTING.md` 四条铁律）

1. **主体相关**：必须是中国威士忌的酒厂 / 产区 / 产品 / 产业事实，能挂进 `产区→酒厂→产品` 或 `INDUSTRY_*` 数据模型；白酒渠道事件、非国威品类一律不收。
2. **出处可查**：每条必须有可访问来源；一手（政府 / 协会 / 标准机构 / 厂方公告 / 赛事官网）优先，二手需独立交叉——**同一场发布会被三家媒体转述 ≠ 三源交叉**。
3. **不编造**：价格、工艺、品鉴无一手来源一律 `pending` 或留空；AI 只整理不判断。
4. **去重优先**：与库内条目重复者判「更新」而非「新增」；与库内已核实值冲突者**不得直接覆盖**。
5. **证据分级**：`verified` = 一手可点开逐字符核对；`pending` = 二手 / 企业方单方口径；`unverified` = 无法核验（不入库）。

## 六、三条口径张力的独立裁定

### (a) 崃州菲诺雪莉桶：279 元 vs 359 元 → **不覆盖，双记**
359 元出自每经「记者线上调查」，配图说明为「崃州蒸馏厂公众号截图」——属**渠道观察价**；279 元为研报/行业盘点口径。**保留 279 元 verified，359 元写入 `note` 并标 pending。**
附带疑点：库内 STR 与菲诺**同为 279 元**，而 WWA 官网显示获奖 Bourbon Cask Peated Malt 为 **50%vol**、库内泥煤波本为 **46%vol** → 价格与规格自洽性建议一并复核。

### (b) 「64 家」→ **改为「在建及投产项目 64 个（51 已投产 / 2 试生产）」**
算术闭合（51+2=53，余 11 在建）证明 64 ≠ 已投产。但每经原文亦作「生产厂家」，属**源间措辞不一**，宜在 note 注明两种措辞，而非判定库内单方出错。

### (c) 「进口 85% / 国产 15%」与「国产产量已超越进口量」→ **不矛盾，但须补口径**
每经原文为「**市场占有率**达到 85%」（份额口径）；新华网何勇致辞为「**产量**已超越进口量」（蒸馏量口径，7 万千升 > 3584 万升）。二者维度不同可并存；须为 :566/:567 补「市场份额口径」，并区分「消费者体验率 85%」与「居家独酌场景 85%」两个同形数字。

## 七、反证：6 类「看起来能收、其实是软文/伪多源」的陷阱

- **R1｜企业专版被当双源**：亳州晚报 80 万元报道所属版面为「第 09 版：古井」（古井贡酒企业专版），新华网同事件稿**全文未提成交价** → 并非两个独立来源。
- **R2｜伪多源**：「64 家 / 7 万千升 / 158.5 亿 / 300-500 元占 55%」在每经、糖烟酒周刊、新华网三处措辞一致，但**三者转述的是同一场 2026-09-19 发布会**，上游只有中酒协报告（原文未取得）。
- **R3｜企业方自述当事实**：「将成全球规模最大单体单一麦芽酒厂」（大芹田雷）、「年产值突破 60 亿」（久溪许碧玉）、青岛 5 款免税工艺（韩媒明文「회사 측은 설명」= 企业口径）→ 一律 pending。
- **R4｜因来源可疑而连带否决真实事实**：B 线把叠川 ISC 金奖与崃州 93.87 分同判「不收」，但华夏酒报 2026-09-29 独立记载了叠川 2024 年 ISC 金奖 → AI 页不可作来源，不应连带否决行媒已载事实。
- **R5｜同一媒体序列冒充双源**：隐象两条报道同属淳安县融媒、同一通讯员 → 补华夏酒报具名列举后才成立。
- **R6｜来源外挂**：「8 条生产线」不在惠州日报（已 GBK 解码核对），出自酒业家；「浙大试种大麦」「6 万桶洞藏酒库」在 A 线自引两源中**均不存在** → 已标暂缓。
